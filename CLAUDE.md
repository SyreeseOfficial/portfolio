# Portfolio

- Next.js static site on Vercel. `npm run dev` / `npm run build`. See README "Where things live".
- Posts: `content/posts/<slug>.md` with title, date, summary front matter.
- Changelog: `content/changelog/` (home shows the newest four).
- Each project needs `public/uploads/projects/<slug>.webp` and `<slug>-thumb.webp` or the build fails.
- Git commits: put `[skip ci]` in the commit message.
